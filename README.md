# متجر عربي – واجهة Frontend

مشروع واجهة متجر عربي RTL باستخدام HTML وCSS وBootstrap 5 RTL وVanilla JavaScript.

## التشغيل
- فك ضغط المشروع.
- افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا بسيطًا من مجلد المشروع.
- يتطلب تحميل Bootstrap وBootstrap Icons وخط Cairo اتصالًا بالإنترنت.

## الصفحات والملفات
- `index.html`: الصفحة الرئيسية وأقسام المتجر والباقات.
- `product-details.html`: تفاصيل المنتج ومعرض صور متحرك يدويًا وتلقائيًا.
- `product-details.js`: بيانات الباقات وسلوك معرض الصور.
- `checkout.html` و`checkout.js`: واجهة إتمام الطلب والدفع عند الاستلام (تجريبية فقط).
- `cart.js`: إدارة سلة المشتريات باستخدام LocalStorage.
- `app.js`: تفاعلات الصفحة الرئيسية.
- `styles.css`: تنسيقات الموقع والسلة والتفاصيل وإتمام الطلب.
- `assets/product-1.svg` إلى `assets/product-3.svg`: صور توضيحية مؤقتة لمعرض الصور.

## سلة المشتريات والطلب المباشر
- زر **أضف إلى السلة** يضيف الباقة إلى `shopping_cart` في LocalStorage.
- زر **اطلب الآن** يفتح `checkout.html?package=PACKAGE_ID` ويعرض الباقة المحددة كطلب مباشر بكمية واحدة، دون تعديل محتويات السلة المحفوظة.
- صفحة تفاصيل المنتج تُفتح من رابط **تفاصيل المنتج** أسفل أزرار كل باقة، وتعرض سعر الباقة المختارة.
- يمكن استبدال الصور المؤقتة بصور المنتج الفعلية مع الاحتفاظ بالأسماء أو تعديل مصفوفة الصور في `product-details.js`.
- أضف الاسم والوصف والوزن/الحجم الفعلي للمنتج في `product-details.html` قبل النشر.

## ملاحظات مهمة
- الأسعار معرفة في JavaScript من أسعار الباقات الحالية، ولا يتم اعتماد أسعار LocalStorage.
- لا يوجد Backend أو حفظ طلبات حقيقي أو إرسال بيانات عميل. نموذج إتمام الطلب يتحقق من الحقول محليًا فقط.
- عند تنفيذ نسخة ASP.NET Core MVC لاحقًا يجب إعادة التحقق من معرفات الباقات والأسعار والكميات على الخادم قبل إنشاء الطلب.
- رقم واتساب الحالي تجريبي وقابل للتعديل في روابط `wa.me` داخل `index.html`.
- صفحة إتمام الطلب تعرض محدد كمية مستقل لكل باقة (+ / −)، وتحدّث إجمالي كل صنف والإجمالي النهائي فورًا. في الطلب المباشر يبدأ العدد من 1 ولا تتغير السلة المحفوظة، أما طلب السلة فيحفظ الكميات المعدلة في `localStorage`.
